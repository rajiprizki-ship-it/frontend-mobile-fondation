# Web Explore Destinasi Wisata Rancabali

## Deskripsi
Website yang digunakan untuk membantu pengguna menemukan
informasi mengenai destinasi wisata di Rancabali.

## Fitur
- Melihat daftar destinasi wisata
- Melihat detail destinasi
- Mencari destinasi
- Melihat kategori wisata
- Melihat lokasi
- Melihat jam buka
- Melihat fasilitas
- Memberikan rating dan ulasan
- Login pengguna
- Halaman admin

## Teknologi
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Anggota Tim
- Siswa 1:Rajip Frontend
- Siswa 2:Loeshni Backend

## Struktur Project
- `index.php` → halaman utama
- `config/` → konfigurasi dan koneksi database
- `database/` → file database
- `assets/` → CSS, JavaScript, dan gambar
- `admin/` → halaman admin
